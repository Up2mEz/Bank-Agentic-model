ทดสอบคำขอด้วยการกรอกข้อมูลเอง

สร้างเคสทดสอบใน local sandbox · ช่องทางรับสมัครลูกค้าจริงยังเป็น Android ผ่าน Go gateway · ใช้ข้อมูลสังเคราะห์สำหรับการทดลอง

ยังไม่ได้สร้างเคส

1สร้างเคสทดสอบ

กรอกข้อมูลผู้สมัครและร้าน แล้วสร้างเคสก่อนแนบเอกสาร ข้อมูลที่สร้างแล้วจะคงเดิมเพื่อให้ตรวจผลซ้ำได้

2แนบเอกสาร

เลือกอัปโหลดไฟล์ของเคสนี้ หรือเพิ่ม bundled sample อย่างชัดเจน แต่ละปุ่มเป็นคำสั่งแยกกัน

ไฟล์อัปโหลดยังไม่ได้ OCR หรือแยกประเภทรายการ ต้องเลือก Typhoon เพื่ออ่านไฟล์จริง หากไม่มี recorded OCR จะใช้ Offline ไม่ได้

ใช้ PDF ตัวอย่างสังเคราะห์พร้อม recorded OCR

Bundled sample: Mali Jaidee · บัญชี TEST-0001 เป็น PDF สังเคราะห์ที่จับคู่ recorded OCR ด้วย SHA-256 ตรงไฟล์ ไม่มีการเรียก OCR ใหม่หรือ LLM ใน Offline ชื่อในใบสมัครควรตรงกับตัวอย่างหากต้องการทดสอบเคสที่ชื่อสอดคล้องกัน

3เริ่มตรวจหลักฐาน

Offline ใช้ recorded OCR ของเอกสารที่เก็บไว้เท่านั้น ไม่เรียก LLM และไม่อ่าน PDF ใหม่ ส่วน Typhoon เรียก OCR/โมเดลจริงตามที่บริการตั้งค่าไว้
